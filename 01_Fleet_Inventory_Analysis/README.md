# Fleet Inventory Analysis

## Project Overview
This project involves analysing fleet inventory data using Microsoft Excel.

## Objective
To organise, examine and interpret fleet inventory information to understand inventory distribution and identify relevant patterns.

## Tools Used
- Microsoft Excel

## Skills Applied
- Data organisation and cleaning
- Sorting and filtering
- Excel formulas and functions
- Data analysis and interpretation
