# Data Visualization and Dashboards with Excel and Cognos

## Course Overview
This course was completed as part of the IBM Data Analyst Professional Certificate on Coursera.

The course focused on developing data visualisation and dashboarding skills using Microsoft Excel and IBM Cognos Analytics.

## Tools Covered
- Microsoft Excel
- IBM Cognos Analytics

## Key Learning Areas
- Data visualisation principles
- Creating charts and visual representations of data
- Designing interactive dashboards
- Presenting analytical insights through visualisations
- Dashboard development using Excel and Cognos Analytics

## Practical Assignments
This folder contains the practical assignments and dashboard work completed during the course.

## Learning Outcomes
- Understanding data visualisation techniques.
- Developing skills in dashboard design and presentation.
- Communicating data-driven insights through visual analytics.

IBM Data Analyst Professional Certificate – Coursera.
