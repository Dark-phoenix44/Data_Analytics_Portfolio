# Databases and SQL for Data Science with Python

## Course Overview
This course, offered by IBM through Coursera, focuses on relational databases, SQL queries, and accessing databases using Python for data analysis.

## Tools and Technologies
- SQL
- MySQL
- SQLite
- IBM Db2
- Python
- Jupyter Notebook

## Technical Skills Covered
- Database fundamentals and relational database concepts
- SQL queries using SELECT, INSERT, UPDATE, DELETE, COUNT, DISTINCT, LIMIT
- Filtering, sorting and grouping data
- Aggregate functions and built-in database functions
- Creating and modifying tables using DDL commands
- Subqueries and nested queries
- Working with multiple tables
- Database connectivity using Python
- Querying databases using SQL Magic and SQLite
- JOIN operations, views and transactions
